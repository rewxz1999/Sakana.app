# Sakana 🐟

番剧管理及播放桌面客户端（Windows）。追番、订阅下载、本地与在线播放，收在一个界面里。

## 功能

- **番剧表**：每日放送、按周切换，卡片一键收藏
- **搜索**：番剧搜索 + 书签（左侧滑动列表，可重命名、删除）
- **收藏 / 订阅**：收藏按年份整理、可标记已看完；订阅蜜柑计划资源并自动下载
- **下载**：内置下载器，完成后自动整理命名，可直接播放
- **在线播放**：规则引擎（支持导入 Kazumi 规则），自动解析剧集并播放；支持选集、自动连播、断点续播
- **弹幕**：在线与本地播放都能显示弹幕，可调覆盖区域 / 数量 / 时间轴与字号等
- **本地播放**：整个文件夹当播放列表、字幕、倍速、截图、画面比例
- **播放器**：libmpv / libVLC 双内核，控制栏、选集、详情浮层，可自定义快捷键
- **仪表盘 / 统计**：观看历史、订阅动态、收藏分布、年度统计
- **系统托盘**：关闭可最小化到托盘，托盘悬浮显示下载进度与观看动态
- **设置**：主题配色、数据源、下载器、路径、快捷键、运行日志

## 开发

```bash
npm install     # 首次安装（使用 npmmirror 镜像源）
npm run dev     # 开发模式
npm run build   # 构建
```

> 内置运行时的获取与原生模块编译见 `package.json` 的 `*:fetch` / `mpv:build` 脚本（需要 VS Build Tools 与 Python 3）。

## 目录结构

```
src/
├── main/            # Electron 主进程（窗口、存储、IPC、服务）
│   ├── services/    # 数据源 / 订阅 / 下载 / 播放内核 / 规则引擎
│   └── lib/         # 标题解析、命名规则
├── preload/         # contextBridge 类型化桥接
├── shared/          # 主/渲染共用类型与 IPC 契约
└── renderer/        # React 界面（页面、组件、状态、主题）
native/
└── mpv/             # libmpv 原生插件（N-API）
resources/           # 内置运行时（libvlc / libmpv / ffmpeg / aria2，体积大不入库，见 fetch 脚本）
```

## 数据源

| 用途 | 来源 |
|------|------|
| 番剧数据 | Bangumi（自建反代优先，反代不可用时提示切换镜像站） |
| galgame 数据 | 月幕 galgame、VNDB |
| 资源站 | 蜜柑计划 |
