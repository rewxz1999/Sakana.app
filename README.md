# Sakana 🐟

番剧管理及播放桌面客户端（Windows）。追番、订阅下载、本地与在线播放，收在一个界面里。

## 功能

- **番剧表**：每日放送、按周切换，卡片一键收藏
- **搜索**：番剧搜索 + 书签（左侧滑动列表，可重命名、删除）
- **收藏 / 订阅**：收藏按年份整理、可标记已看完；订阅蜜柑计划资源并自动下载
- **下载**：内置下载器，完成后自动整理命名，可直接播放
- **在线播放**：规则引擎（支持导入 Kazumi 规则），自动解析剧集并播放；支持选集、自动连播、断点续播
- **弹幕**：在线与本地播放都能显示弹幕，可调覆盖区域 / 数量 / 时间轴与字号等；渲染可选内置画布或内置的 mpv 插件 uosc_danmaku（带弹幕搜索 / 样式 / 延迟菜单）；另支持 B 站弹幕（mpv 脚本，需自备 yt-dlp / biliass）
- **本地播放**：整个文件夹当播放列表、字幕、倍速、截图、画面比例
- **播放器**：libmpv 内核，控制栏（含音量滑杆）、选集、详情浮层，可自定义快捷键
- **画质增强**：内置 Anime4K 超分（39 个官方 GPU 着色器，6 种模式 × 流畅/画质两档，支持自定义着色器链），另有饱和度 / 对比度 / 亮度 / 伽马微调与 HDR 色调映射，播放中改设置即时生效
- **仪表盘 / 统计**：观看历史、订阅动态、收藏分布、年度统计
- **系统托盘**：关闭可最小化到托盘，托盘悬浮显示下载进度与观看动态
- **设置**：主题配色、数据源、下载器、路径、快捷键、运行日志

## 开发

```bash
npm install     # 首次安装（使用 npmmirror 镜像源）
npm run dev     # 开发模式
npm run build   # 构建
```

> 内置运行时的获取与原生模块编译见 `package.json` 的 `*:fetch` / `mpv:build` 脚本（需要 VS Build Tools 与 Python 3）。

## 目录结构

```
src/
├── main/            # Electron 主进程（窗口、存储、IPC、服务）
│   ├── services/    # 数据源 / 订阅 / 下载 / 播放内核 / 规则引擎
│   └── lib/         # 标题解析、命名规则
├── preload/         # contextBridge 类型化桥接
├── shared/          # 主/渲染共用类型与 IPC 契约
└── renderer/        # React 界面（页面、组件、状态、主题）
native/
└── mpv/             # libmpv 原生插件（N-API）
resources/           # 内置运行时（libvlc / libmpv / ffmpeg / aria2，体积大不入库，见 fetch 脚本）
```

## 更新记录

### 0.3.3

- **播放器控制栏改回自建**，并在控制栏里加了「画质（Anime4K 超分）」按钮：直接切换关闭 / 模式 A / B / C / A+A / B+B / C+A 与流畅·画质两档，播放中即时生效；原 uosc 控制栏改为可选（默认关闭），设置页可随时切回
- 修复**控制栏按钮与菜单点了没反应**：mpv 把动作字符串加了一层引号（`user-data` 是节点类型属性），导致每个按钮/菜单项都匹配不上 —— 这是从 0.3.0 起「按钮全无效」的真因
- **订阅改用蜜柑自己的 RSS 订阅地址**（按番剧 + 字幕组直接拉取），不再依赖关键词搜索后自行过滤，不再串番与漏资源
- **「最XX的角色」立绘完整显示**：竖长立绘原先被裁掉约 30%，现在默认完整可见、多余区域用同图模糊背景填充，并提供「完整显示 / 铺满裁剪」切换（预览与导出共用同一套绘制）
- **角色立绘改用 Bangumi 原图**（CLANNAD 角色实测 2434×3466，与 bgm.tv 角色页同一张；此前误取了 75×75 的缩略图）；角色数据源改为 Bangumi 优先、Jikan 备选

### 0.3.2

集中修复 0.3.1 反馈的问题：

- **播放器控制栏**：修掉「旧控制栏还在、uosc 呼不出来、点了没反应」—— uosc 接管时透明悬浮窗不再抢占鼠标（原来鼠标一动它就变成可点击窗口，整窗盖住视频，mpv 收不到任何鼠标事件），现在鼠标能正常到 mpv，uosc 控制栏可正常唤出；详情 / 选集等浮层也补上了缺失的交互依赖
- **番剧条目右键菜单**：修复菜单项点了没反应（捕获阶段 mousedown 先把菜单卸载了）—— 详情 / 重新排序 / 删除条目 / 删除列表全部可用，并支持方向键 + 回车
- **搜索历史下拉**：修好「被搜索结果区盖住、点不动」（header 的 backdrop-filter 造成层叠上下文），点历史标签即可直接搜索
- **「最XX的角色」**：新增可见的数据源切换（Jikan / Bangumi），Jikan 取不到时给出常驻提示与「重试」；九宫格尺寸进一步收紧（单格 156×224、导出 1096×1788），预览与导出尺寸统一，小图不再被硬放大
- **超分辨率设置**：卡片移到播放器设置页最前面，设置总览入口也点名「Anime4K 超分与画质」，不再找不到
- **添加番剧条目**：改用本地缓存的当季番剧数据，重复打开同一季度不再请求网络、同步出候选
- **订阅匹配**：不再把同字幕组的其它番剧当成订阅资源（实测该错误 91 条 → 0 条），同时补回短标题漏配；每次检测都写一行可诊断日志
- **Jikan 备用数据源**：接入主数据源链路，反代全部失效时自动使用（严格 3 次/秒、60 次/分钟节流）
